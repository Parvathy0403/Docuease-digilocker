# DocuEase — Smart Document Assistant

A beginner-friendly Full Stack Development practical project inspired by the DigiLocker user journey. It demonstrates document search, status filtering, document details, form validation, and a simulated sharing request.

## Technologies
- HTML
- CSS
- JavaScript

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Search for documents, use the status filters, select a document, and test the sharing form.

## Features
- Search by document name or category
- Filter documents by status
- Show document details and next steps
- Validate required fields and email format
- Prevent sharing a pending sample document
- Show a simulated confirmation message

## Important note
This is a demonstration project. It uses sample data and is not connected to the official DigiLocker service. It does not access or transmit real documents.
